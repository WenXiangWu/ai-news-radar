色彩使用规则

品牌青 #00a3cf → 主强调色：选中态、链接、提莫相关、评分徽章
品牌紫 #7c3aed → 次强调色：分类标签、渐变点缀、热点 TOP2
辉光青 #00d4ff → 光晕效果：简报卡背景渐变、hover glow
所有 border → rgba(15,23,42,0.08)，和主站一致
圆角 → 22px（大容器）/ 12px（卡片）/ 999px（按钮），沿用主站规范

角色方案：只有提莫

提莫是侦察兵，天然适合"雷达"概念。其他角色全部移除，提莫作为唯一品牌吉祥物

✗ 原版多角色方案
6 个角色各管一个频道：
提莫=全部 / 黑默丁格=精选 / 吉格斯=热点…

✗ 角色太多，用户记不住
✗ 和主站 IP 矩阵冲突
✗ 每个角色要设计头像和配色
✓ 提莫独占方案
提莫 = 雷达的侦察兵 / 品牌吉祥物：
提莫侦察中 = 正在抓取信源
提莫发现了 N 条信号 = 今日更新数
提莫的雷达 = 热点板块

✓ 一个角色足够，辨识度反而更高
✓ 侦察兵 × 雷达 = 天然语义匹配
✓ 频道用分类代替角色（全部/模型/产品/社区…）

去翻译 · 纯中文

移除 i18n 相关代码，所有文案固定为中文

移除项说明
messages/ 目录删除 zh-CN.json / zh-TW.json / en.json / ja.json 四个翻译文件
src/i18n/ 目录删除 routing.ts 和配置文件
next.config.ts 中的 i18n 配置移除 locales / defaultLocale 等配置
组件中的 useTranslation()替换为直接写中文字符串
[locale] 路由段app/[locale]/ 改为 app/，去掉语言前缀路由

注意：这个去 i18n 是针对雷达站点

雷达站（ai-news-radar）目前是纯静态 HTML/JS，本身没有 i18n。如果后续迁移到 Next.js，直接不做 i18n 即可。主站 cyber-blitz 的 i18n 不受影响。

实施路线

三个阶段，总计 3-5 天

Phase 1 · 骨架重建（2 天）

侧栏 + 顶部条 + Bento 棋盘格

彻底替换页面布局结构，这是区分 fork 最关键的一步。

  • 重写 index.html：左侧栏 + 右侧主区的两栏布局
  • 侧栏：品牌 Logo + 提莫 Slogan + 分类导航 + 底部状态
  • 顶部条：频道标题 + 搜索框 + 精选/全量开关 + 更新时间
  • 主区：每日简报卡 + Bento 棋盘格（CSS Grid 6 列）
  • 重写 styles.css：使用主站 lab 皮肤色板
  • 重写 app.js 渲染函数：适配新的 DOM 结构
Phase 2 · 提莫注入 + 独有组件（1-2 天）

每日简报 + 提莫面板 + 信源健康环 + 活动热力图

实现 4 个原版没有的组件，彻底消除 fork 痕迹。

  • 提莫每日简报卡：从 daily-brief.json 读摘要 + 统计数据
  • 提莫状态面板：头像 + 第一人称点评 + 统计项
  • 信源健康环：SVG 圆环 + source-status.json 数据
  • 活动热力图：从历史数据聚合 30 天活动量
  • 所有文案用提莫语气："今天我替你盯了 N 个信源…"
Phase 3 · 打磨 + 上线（1 天）

响应式 + 动效 + 部署

  • 移动端：侧栏折叠为底部 Tab 栏或汉堡菜单
  • meta 标签更新：title="赛博维克托 · 雷达" / og 信息
  • 卡片 hover 效果 + 简报卡背景光晕
  • GitHub Pages 部署验证
  • 原版保留在 classic/ 目录备用
