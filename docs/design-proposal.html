2

设计原则

四个核心原则指导所有视觉决策

🔧

工坊感 · Workshop Aesthetic

界面是维克托的工坊控制台——深色底、发光元素、精密仪表感。每个区块像一个正在运转的机器模块。

👁

义眼焦点 · Single Focus

只用一个强调色（橙）引导视线，其余信息用明度层级区分。像机械义眼一样精准锁定重要内容。

🤖

角色即功能 · Characters as Functions

每个 IP 角色对应一个功能模块：提莫=前沿雷达，黑默丁格=学习路线，吉格斯=热点爆破。用户通过角色理解信息结构。

📐

信息密度不妥协 · Density First

视觉升级不牺牲信息效率。卡片仍是一行一条，时间轴保留，筛选器保持可达。美感服务于可读性。

色彩映射规则

旧 --accent (#126a73 深青) → 新 --orange-main (#FF5A1F 电光橙)，所有主要 CTA、选中态、评分徽章统一换橙。
旧 --accent-warm (#b55231 暖红) → 保留为精选/热门标记色，与主橙形成同色系层次。
旧 --bg (#f6f6f2 暖白) → 新 --ink-black (#0D0D0F 墨黑)，整体翻转为暗色。

组件规范 · Detail Spec

每个关键组件的具体样式规则

组件样式规则
Logo · 机械义眼 48×48 圆角方块(12px radius)，墨黑底 + 细边框。内部是一个发光圆环(橙) + 中心实心圆点(橙)，带 glow 阴影。小尺寸(28px)只保留圆环+点。替代当前的雷达 SVG。
Hero 区 顶部：Logo + 品牌名「赛博维克托 · 雷达」+ 英文副标。Slogan 徽章「加入光荣的进化。」。主标题 H1 36px 粗黑，关键词用橙色。描述文字 14px 灰色。底部状态行：源状态绿点 + 更新时间 + 视角切换。
角色 Tab 每个 Tab = 角色 emoji(20px 圆角方块) + 角色名 + 计数徽章。未选中：透明底 + 灰字。选中：深色底 + 角色专属色边框 + 白字。Hover：微亮背景。Tab 容器有底部 1px 分隔线。
精选/全量开关 双按钮组，选中态用橙色实底白字，未选中透明底灰字。与搜索框同行。
热点排行 标题行：🔥 emoji + 「吉格斯 · 当前热点」。每行：序号(橙/金/铜色) + 标题 + 信源数徽章 + 时间。行间距用 1px 分隔线。TOP3 序号加大加粗。
时间轴卡片 左侧 rail：时间(12px 灰) + 发光圆点(橙/青交替)。右侧卡片：墨黑底(#1A1A20) + 1px 边框 + 10px 圆角。内部：信源名 + 评分徽章(橙) + 分类徽章(角色色) + 精选徽章。标题 15px 粗白。摘要 13px 灰。底部分隔线后是标签 + 查看原文链接(橙色)。
三味点评面板 嵌在卡片底部，3 列网格，列间 1px 竖线。每列：角色名(11px 彩色) + 点评文字(11px 灰)。面板背景比卡片略深。移动端改为单列堆叠。
页脚 1px 顶部分隔线。左侧：小 Logo + 「赛博维克托 · 雷达 — 拆开看，跑起来。」右侧：「加入光荣的进化。」斜体灰色。

动效规范

克制的动效增强赛博感，不牺牲性能

动效规则
义眼 Logo glow CSS animation，呼吸频率 3s ease-in-out，box-shadow 在 8px~14px 间循环。prefers-reduced-motion 时关闭。
卡片 hover translateY(-2px) + box-shadow 增强 + border-color 微亮。transition 200ms ease。
Tab 切换 选中态 border-color 渐变 150ms。对应内容区域 fade-in 200ms。
时间轴圆点 新内容到达时，圆点 pulse 一次（scale 1→1.5→1，400ms），glow 增强后恢复。
热点序号 TOP3 序号有微弱的 text-shadow glow，颜色与序号一致（橙/金/铜）。
卡片入场 保留当前 translateY(12px) → 0 的入场动画，增加 opacity 0→1，时长 300ms。
9

实施路线

分三个阶段，每阶段可独立上线验证

Phase 1 · 视觉翻转（1-2 天）

暗色主题 + 色彩系统替换

最小改动，最大感知变化。替换 CSS 变量即可覆盖 80% 视觉效果。

替换 :root 变量：背景→墨黑，文字→暖白，强调→电光橙
所有 border 从 rgba(23,23,23,0.08) 改为 rgba(255,255,255,0.06)
卡片背景从 #fff 改为 #1A1A20，文字色反转
按钮选中态从深青改为电光橙实底
Logo SVG 替换为机械义眼
Phase 2 · IP 注入（2-3 天）

角色系统 + 品牌文案

将角色映射到功能模块，注入品牌叙事。

栏目 Tab 重构为角色 Tab（emoji + 名称 + 专属色）
Hero 区文案替换：标题、副标、Slogan 徽章
热点板块标题改为「吉格斯 · 当前热点」
精选板块标题改为「黑默丁格 · 精选」
页脚品牌信息替换
meta 标签更新（title / description / og）
Phase 3 · 体验增强（1-2 天）

动效 + 细节打磨

增加赛博感的微交互，打磨视觉细节。

义眼 Logo 呼吸 glow 动画
卡片 hover 效果增强（border glow + shadow）
时间轴圆点 pulse 入场动画
角色 Tab 切换时的内容 fade-in
Hero 区背景 radial-gradient 光晕
评分徽章和热点序号的 text-shadow glow
